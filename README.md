# Linear-Regression-Model

A simple Linear Regression implementation built from scratch using Python and NumPy, featuring an interactive [Streamlit](https://streamlit.io/) web application.

## Overview
This project implements a linear regression class using a custom sampling descent algorithm and Mean Squared Error (MSE) loss function to find optimal parameters without relying on machine learning libraries like `scikit-learn`. It includes an interactive UI for experimenting with hyperparameters in real time.

## Project Structure
* `LinearRegression.py`: Core model class implementing parameter space search, error calculation, and fitting/prediction logic.
* `app.py`: Streamlit frontend application providing an interface to test the model.
* `requirements.txt`: Project dependencies.
